# CASE-001 — Neon Button

> Classification: UI

---

## Objective

Recreate a neon button effect using React and Tailwind CSS.

---

## Motivation

I built this effect years ago with plain HTML and CSS.

This experiment explores how the same concept can be recreated using Tailwind's utility classes while keeping the component reusable.

---

## Stack

- React
- Tailwind CSS
- Vite

---

## Learned

- Utility-first styling
- Hover transitions
- Reusable React components
- Custom glow effects
