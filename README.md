## What is Archive Zero?

**Archive Zero** is my personal archive of coding experiments.

Instead of building complete applications every time I learn something new, I create small, focused experiments that explore one idea at a time.

Some experiments become future projects.

Some stay here as reminders of what I learned.

None of them are wasted.

---

## Philosophy

Small experiments.

Curiosity over perfection.

Build → Break → Learn → Repeat.

---

## Structure

Each experiment lives in its own folder and is documented as a **CASE**.

```text
CASE-001-neon-button
CASE-002-glass-card
CASE-003-cursor-glow
...
```

Every case includes:

* 🎯 Objective
* 💡 Motivation
* 🛠️ Technologies
* 📖 What I learned
* ⚠️ Challenges
* 📸 Preview
* 📝 Notes
